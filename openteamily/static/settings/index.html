‹ 技能配置

用于技能授权

部分技能需要 API Key 才能调用第三方服务。请在此添加密钥，名称须与技能声明的名称完全一致（区分大小写，例如 MY_API_KEY）。配置值加密存储，仅在技能运行时使用，不会在对话中展示。
